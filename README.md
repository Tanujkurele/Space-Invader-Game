# 🚀 Tanuj's Space - Space Invaders Game

A 2D Space Invaders-style arcade game developed using **Python and Pygame** as a 3rd-semester B.Tech Computer Science Engineering minor project.

About the Project

Tanuj's Space is a simple 2D shooting game in which the player controls a spaceship and shoots incoming enemies to score points.

The game features player movement, enemy movement, bullet shooting, collision detection, score tracking, and a game-over condition.

Features

- Player spaceship movement using left and right arrow keys.
- Shoot bullets using the spacebar.
- Multiple enemies moving across the screen.
- Automatic enemy direction changes at screen boundaries.
- Collision detection between bullets and enemies.
- Game-over condition when enemies reach a certain height.

Technologies Used

- **Programming Language:** Python
- **Game Development Library:** Pygame
- **IDE:** Visual Studio Code
- **Concepts Used:** Loops, Functions, Lists, Conditional Statements, Random Module and Collision Detection.

Installation and Setup

1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Tanuj-Space-Invaders.git
```

2. Navigate to the Project Folder

```bash
cd Tanuj-Space-Invaders
```

3. Install Dependencies

```bash
pip install -r requirements.txt
```

4. Run the Game

```bash
python main.py
```

Game Controls

| Key Action |
| ← Left Arrow | Move spaceship left |
| → Right Arrow | Move spaceship right |
| Spacebar | Shoot bullets |
| Close Window | Exit the game |
